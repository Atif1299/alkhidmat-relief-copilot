# Shelter — Temporary camp placement

**Category:** Shelter  
**Keywords:** shelter, camp, panah, dera, tent, displaced, homeless, ghar, house, rehne, place, stay  
**Default:** yes

## Purpose

Place displaced families in a temporary camp that has space for them.

## Rules

1. Confirm the number of families and people, and whether they need to stay overnight.
2. Match a camp with remaining capacity; each unit of stock is one family slot.
3. Prefer a camp in the same area: Johar Town, Township, Gulberg, Raiwind or Thokar Niaz Baig.
4. More than five families in one request is priority high; tell the supervisor if capacity is tight.
5. The ticket includes the camp name and reporting instructions.
