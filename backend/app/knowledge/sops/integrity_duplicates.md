# Integrity — Duplicate requests

**Category:** Integrity  
**Keywords:** duplicate, repeat, same phone, again, fraud, integrity

## Purpose

Stop the same household drawing stock twice without blocking genuine new needs.

## Rules

1. A request from a phone that made any request in the last 48 hours goes to supervisor review.
2. Nobody is rejected automatically; the requester still receives an AKD number.
3. The supervisor checks whether it is a genuinely new need, such as a different category or an emergency.
4. Approve to continue matching; reject to close the case as not approved.
5. Every decision is logged with who made it and when.
