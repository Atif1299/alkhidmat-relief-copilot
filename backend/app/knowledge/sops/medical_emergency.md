# Medical — Life-threatening emergencies

**Category:** Medical  
**Keywords:** chest, pain, seena, dard, breathing, saans, unconscious, behosh, bleeding, ambulance, emergency, accident, heart, stroke, critical  
**Default:** yes

## Purpose

Route life-threatening medical requests safely, with a person approving before the NGO commits resources.

## Rules

1. Chest pain, difficulty breathing, unconsciousness or severe bleeding set priority to critical.
2. Critical cases pause for supervisor approval before a resource or volunteer is assigned.
3. The requester is shown a Rescue 1122 prompt immediately, before any approval.
4. After approval, match the nearest ambulance post or first-aid unit in the same area.
5. Record a landmark and a working phone number for the field team.
6. Assign a volunteer with medical skills when one is available.
