# Blood Request SOP

**Category:** Blood  
**Keywords:** blood, donor, transfusion, bank, O+, A+, B+, AB, sundas

## Purpose

Match blood requests to Lahore blood banks with type awareness.

## Rules

1. Capture blood group if stated; if missing, still open ticket and note "type TBD".
2. Prefer Sundas Foundation or Alkhidmat Blood Centre by proximity.
3. Urgent transfusion / surgery today → priority **high** or **critical**.
4. Critical blood cases require HITL before volunteer assign.
5. Never invent stock of rare types; use seeded stock counts only.
