# Shelter SOP — Temporary Camps

**Category:** Shelter  
**Keywords:** shelter, camp, tent, housing, displaced, rain, flood, family

## Purpose

Place displaced families in temporary camps with capacity checks.

## Rules

1. Confirm number of families/persons and whether overnight stay is needed.
2. Match to camp with remaining capacity (stock treated as family slots).
3. Prefer same area; else nearest Lahore camp (Johar Town, Raiwind).
4. Large groups (>5 families) → priority **high**; notify supervisor if capacity tight.
5. Issue ticket with camp name and reporting instructions.
