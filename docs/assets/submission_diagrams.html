LangGraph agent pipeline

Integrity is never skipped on create. Critical / duplicate / high-risk cases pause at HITL.

flowchart TD
  START([START]) --> IN[Intake
language · need · location · phone]
  IN --> TR[Triage
category + priority]
  TR --> KN[Knowledge
SOP RAG pgvector / keyword]
  KN --> IG[Integrity
duplicate · risk score]
  IG -->|normal| MT[Matcher
inventory + volunteer]
  IG -->|critical / duplicate / high risk| HITL[HITL Gate
LangGraph interrupt]
  HITL -->|approve| MT
  HITL -->|reject| REJ([END · rejected])
  MT --> DP[Dispatch
AKD ticket + notify]
  DP --> ENDN([END · dispatched])
Always runs HITL interrupt Ticket = winning signal

Citizen journey — request to status

Guest submit streams live agent steps. AKD number minted at intake (including HITL holds).

sequenceDiagram
  actor Citizen
  participant Web as Next.js /request
  participant API as FastAPI
  participant Graph as LangGraph
  participant DB as Postgres
  participant Qwen as DashScope Qwen

  Citizen->>Web: Open Request aid (no login)
  Citizen->>Web: Submit Urdu/English need
  Web->>API: POST /api/v1/chat (SSE guest)
  API->>Graph: run pipeline
  Graph->>Qwen: Intake + Triage
  Graph->>DB: Knowledge + Integrity tools
  Graph-->>API: agent_step events
  API-->>Web: live pipeline strip
  alt Normal case
    Graph->>DB: Matcher + Dispatch
    API-->>Web: AKD ticket + match
  else HITL required
    Graph-->>API: pending_hitl (still has AKD)
    API-->>Web: Waiting for supervisor
  end
  Citizen->>Web: /status with AKD + phone
  Web->>API: POST /public/status
  API->>DB: verify ticket + phone
  API-->>Web: public sitrep (no staff fields)

HITL supervisor gate

Pause before Matcher/Dispatch. Approve resumes; reject closes with audit trail.

flowchart LR
  IG[Integrity flags risk] --> Q{HITL needed?}
  Q -->|No| M[Matcher → Dispatch]
  Q -->|Yes| P[Pause · interrupt_before hitl_gate]
  P --> SUP[Supervisor /supervisor]
  SUP -->|Approve| M
  SUP -->|Reject| X[Case rejected + audit]
  M --> T[AKD ticket created]
  T --> C[Citizen /status shows dispatched]
  P --> W[Citizen /status shows waiting]
